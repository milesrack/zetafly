## Requirements

- Node.js 24.12–24.x
- Docker with Docker Compose 2.24.4+
- Git
- macOS, Linux, or WSL
- 4 GB available RAM

## Installation

```sh
git clone https://github.com/milesrack/zetafly.git
cd zetafly
npm ci
npm run setup
docker compose up --build -d
```

- **App:** [localhost:3000](http://localhost:3000)
- **Email:** [localhost:8025](http://localhost:8025)

## Configuration

Edit `.env` for production:

| Variable             | Value                                                            |
| -------------------- | ---------------------------------------------------------------- |
| `MONGODB_URI`        | Empty for Docker MongoDB, or an external connection string       |
| `MONGODB_DATABASE`   | `zetafly`                                                        |
| `BETTER_AUTH_SECRET` | Generated by `npm run setup`                                     |
| `BETTER_AUTH_URL`    | `http://localhost:3000` locally, your HTTPS origin in production |
| `RESEND_API_KEY`     | Empty locally, your Resend API key in production                 |
| `EMAIL_FROM`         | Local default, or a sender on your verified domain               |

## Deployment

Merges to `main` deploy through GitHub Actions.

### Setup

On a Debian or Ubuntu host with Docker Engine and Docker Compose installed, install the remaining packages:

```sh
sudo apt-get update
sudo apt-get install apache2 certbot rsync
sudo a2enmod ssl proxy proxy_http headers
```

Create the deployment account and install the production `.env`:

```sh
sudo adduser --disabled-password --gecos "" deploy
sudo usermod -aG docker deploy
sudo install -d -o deploy -g deploy /var/www/zetafly/releases /var/www/zetafly/shared
sudo install -m 600 -o deploy -g deploy .env /var/www/zetafly/shared/.env
```

Point the DNS names at the host, then issue the certificates:

```sh
sudo install -d /var/www/letsencrypt
echo 'Alias /.well-known/acme-challenge/ /var/www/letsencrypt/.well-known/acme-challenge/' |
  sudo tee /etc/apache2/conf-available/zetafly-acme.conf >/dev/null
sudo a2enconf zetafly-acme
sudo apache2ctl configtest && sudo systemctl reload apache2
sudo certbot certonly --webroot -w /var/www/letsencrypt -d poosd.dev -d www.poosd.dev
sudo certbot certonly --webroot -w /var/www/letsencrypt -d zetafly.poosd.dev
```

From the repository root, enable the Apache site:

```sh
sudo install -m 644 deploy/apache/zetafly.conf /etc/apache2/sites-available/zetafly.conf
sudo a2ensite zetafly
sudo a2disconf zetafly-acme
sudo apache2ctl configtest && sudo systemctl reload apache2
```

For another domain, update the Apache hostnames, certificate paths, and deployment workflow URLs.

Add the deployment public key to `~deploy/.ssh/authorized_keys`, then in GitHub's `production` environment, set:

- **`DEPLOY_SSH_KEY`:** Deployment private key (secret).
- **`DEPLOY_HOST`:** Server hostname (variable).
- **`DEPLOY_KNOWN_HOSTS`:** Verified SSH host key entry (variable).

On the host, release directories and the current deployment are located at:

- **Releases:** `/var/www/zetafly/releases`
- **Current release:** `/var/www/zetafly/current` (symlink to the active release).

### Backup

To back up the MongoDB database and production `.env`:

```sh
umask 077
backup_dir=$(mktemp -d "$HOME/zetafly-backup.XXXXXXXX") &&
  cd /var/www/zetafly/current &&
  docker compose -p zetafly --env-file .env --env-file image.env \
    -f compose.yaml -f compose.production.yaml \
    exec -T mongo mongodump --archive --gzip > "$backup_dir/mongodb.archive.gz" &&
  install -m 600 /var/www/zetafly/shared/.env "$backup_dir/.env"
```

### Recovery

To roll back, replace `PREVIOUS_RELEASE_SHA` with the previous release directory name:

```sh
release=/var/www/zetafly/releases/PREVIOUS_RELEASE_SHA
cd "$release" &&
  docker compose -p zetafly --env-file .env --env-file image.env \
    -f compose.yaml -f compose.production.yaml \
    up -d --no-build --wait --wait-timeout 180 &&
  curl --fail --silent --show-error http://127.0.0.1:3000/api/health &&
  ln -sfn "$release" /var/www/zetafly/current
```

## Training

```sh
uv venv --python 3.12 output/venv
uv pip install --python output/venv/bin/python -r research/connectome-arithmetic/requirements.txt
npm run model:fetch
output/venv/bin/python research/connectome-arithmetic/train.py --output output/model --seconds 120
npm run model:predict -- --model output/model/weights.npz --expression '17*6'
npm run model:inspect -- output/model/weights.npz
```

Upload `output/model/weights.npz` in **Settings → Weights**.
